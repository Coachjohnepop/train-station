# Jeremy — Copy Adult week → Athletes / Military

**Site:** https://www.thetrainstation.co  
**Time:** ~10–15 min for the safe path (one week)  
**What this answers:** Can I reuse Adult Strength content on Athletes and Military without breaking Adult (or stuff I already built)?

**Short answer:** Yes — if you use **Templates & paste**. Adult is never rewritten. Only the day/month you paste **into** changes.

---

## Before you start

1. Incognito + hard refresh (**Cmd/Ctrl + Shift + R**).
2. Pick a **quiet week** on Athletes / Military (empty days, or days you’re OK replacing).
3. Optional tag in template names so we can find them later: `ADULT-XFER` (e.g. `ADULT-XFER · Mon Gym`).

### What is safe vs what overwrites

| Action | Touches Adult? | Touches target program? |
|--------|----------------|-------------------------|
| Save Adult day as **template** | No | No |
| **Paste** template onto Athletes/Military day | No | **Only that day** (Gym/Home tracks you pick) |
| Save Adult **28-day pack** to library | No | No |
| Paste **28-day pack** onto a month | No | Whole month — **asks confirm** if content already exists |
| **Copy week** (Week 1 → 2) | Only if you’re *on* Adult | **Only that program** — target week replaced with independent copies |

**Copy week does not jump programs.** There is no “Copy Adult Week 1 → Athletes Week 1” button. Same program only (Athletes W1 → Athletes W2, etc.).

---

## Path A (recommended): one day at a time — safest

Use this if Athletes/Military already have some good days. You control exactly what gets replaced.

### A1. On Adult — save a day as a template

1. **Admin → Programs → Adult Strength** (or **Adult Strength Conditioning** — whatever label you see).
2. Open a day that looks right (e.g. **Week 1 Monday · Gym**).
3. Open **Templates & paste** (violet control on the program builder).
4. Under **Save current workout as template**:
   - **Name:** e.g. `ADULT-XFER · Mon Gym`
   - **Category:** freeform — try `adult` or `strength` (or type anything)
   - **Version tag (optional):** `v_adult`
5. Tap **Promote to template library**.

**Pass:** Toast/message like “Saved template … — paste anytime (always a fresh copy).”

Repeat for **Home** on the same day if you use both tracks (two templates).

### A2. On Athletes — paste onto an empty (or OK-to-replace) day

1. **Admin → Programs → Athletes** (Speed / Strength / Conditioning — your Athletes program).
2. Select the day you want (start with **empty** Week 1 Monday if you’re unsure).
3. Open **Templates & paste** again.
4. **Paste workout → this day**:
   - Source: **Template library**
   - Pick your `ADULT-XFER · Mon Gym`
   - Check **Gym track** (and/or **Home** if you want both)
5. Tap **Paste as copy**.

**Pass:**
- That day now has exercises matching Adult.
- Go back to **Adult** same day → **still the original** (not emptied, not linked).
- Change sets/reps on **Athletes** only → Adult still unchanged.

### A3. Same for Military

1. **Admin → Programs → Military Preparation**.
2. Same steps: pick day → **Templates & paste** → pick template → **Paste as copy**.

**Pass:** Military day filled; Adult + Athletes untouched (unless you pasted there too).

### A4. After Week 1 exists on Athletes/Military — use Copy week *inside* that program

1. Stay on **Athletes** (or Military).
2. Finish Mon–Sun for Week 1 the way you like (paste more days, or edit).
3. Jump to **Week 2** → **Copy from week 1** / **Copy to this week** (same buttons you use on Adult).

**Pass:** Week 2 is independent copies. Edit Week 2 Monday → Week 1 Monday stays put. **Adult is not involved.**

---

## Path B: whole month via 28-day pack (faster, bigger blast radius)

Use when Athletes or Military month is **empty** (or you’re ready to replace the whole month).

### B1. Snapshot Adult month → library

1. On **Adult**, open **Templates & paste**.
2. Under **28-day cycle pack**, name it e.g. `Adult Strength · M1 · ADULT-XFER`.
3. Tap **Save M1 → library** (or the save control for the current month).

**Pass:** Pack appears in the library list. Adult calendar unchanged.

### B2. Paste onto Athletes (or Military)

1. Open **Athletes** (or Military).
2. **Templates & paste** → pick the library pack → choose month slot → paste.
3. If the month **already has content**, a confirm dialog appears:
   - **Cancel** → nothing changes (good).
   - **OK / Replace** → month becomes a **fresh clone** of the pack (cannot undo easily — only cancel if unsure).

**Pass:** Month filled with independent clones; Adult pack and Adult program still intact.

---

## What *not* to do

| Don’t | Why |
|-------|-----|
| Expect **Copy week** on Adult to fill Athletes | Copy week is same-program only |
| Paste a 28-day pack onto a month you’re proud of without reading the confirm | Full month replace if you accept |
| Panic that “workouts are doing something” on copy | Within a program, copy **clones** on purpose so edits stay independent |
